How to Make a "Moving Link" with an Animated GIF Preview

This is a quick technical guide on how to make a URL show an animated preview (a "moving link") when shared on social media platforms like Twitter, Facebook, and LinkedIn.

The Core Concept: Metadata

When you share a link, social platforms crawl the URL and look for specific <meta> tags in the HTML <head> to build a preview card. To create an animated preview, you simply tell these platforms that your preview "image" is a GIF.

This is achieved using the Open Graph protocol (for Facebook, etc.) and Twitter Cards.

Technical Instructions

Follow these steps to implement an animated preview for any webpage.

Step 1: Prepare Your GIF

Create or find a GIF that you want to use. For best results, optimize it to have a small file size (under 5MB is a good target). Host the GIF at a publicly accessible URL.

Step 2: Add Meta Tags to Your HTML

In the <head> section of your HTML file, add the following code block. Be sure to replace the placeholder content with your own.

<!-- The title of your page -->
<title>Your Page Title</title>

<!-- A brief description of your page -->
<meta name="description" content="A concise and compelling description of your content.">

<!-- Open Graph Tags (for Facebook, LinkedIn, etc.) -->
<meta property="og:title" content="Your Page Title">
<meta property="og:description" content="A concise and compelling description of your content.">
<meta property="og:image" content="https://your-domain.com/path-to-your/animation.gif">
<meta property="og:url" content="https://your-domain.com/your-page.html">
<meta property="og:type" content="website">

<!-- Twitter Card Tags -->
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Your Page Title">
<meta name="twitter:description" content="A concise and compelling description of your content.">
<meta name="twitter:image" content="https://your-domain.com/path-to-your/animation.gif">

Key Points:

  • The og:image and twitter:image tags must point to the direct URL of your .gif file.
  • summary_large_image is the best Twitter card type for showcasing a GIF.
  • Ensure all URLs are absolute (they should start with https://).

Step 3: Validate and Test

After deploying your changes, use official testing tools to ensure your preview appears correctly. Social platforms cache metadata, so you may need to use these tools to force a refresh.

  • Twitter Card Validator
  • Facebook Sharing Debugger
  • LinkedIn Post Inspector

Pasting your URL into these tools will show you a preview of how your moving link will look and alert you to any errors.
